# Assignment 4: File Handling in Python

This repository contains Python scripts demonstrating standard file operations, exception handling, and interactive user input/append tasks.

## Tasks Overview

### Task 1: Read File with Exception Handling (`task1.py`)
* Creates a text file named `sample.txt` and writes initial multi-line contents into it.
* Attempts to open and read a specified target file line-by-line.
* Implements robust error handling using `try...except FileNotFoundError as e` to catch missing files gracefully and display the specific filename that failed to load.

### Task 2: Write and Append Data to File (`task2.py`)
* Prompts the user for initial input and writes it to `output.txt` using `"w"` mode.
* Prompts the user for additional input and appends it to `output.txt` using `"a"` mode.
* Reads and displays the final content of `output.txt` back to the console using `"r"` mode.
